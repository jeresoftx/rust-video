# Benchmarks

Cada benchmark se añade cuando representa una decisión del capítulo. Una cifra
local sin contexto no se presenta como rendimiento de producción.

El draft no incluye una suite de benchmarks ni `criterion`: sus contratos aún
no ejecutan códecs, I/O, renderizado, modelos o una fuente real. El capítulo
07 ofrece una medición local con `Instant` y declara exactamente qué no mide.
Cada capítulo documenta su decisión de benchmark antes de que una dependencia
externa pueda justificarse.
