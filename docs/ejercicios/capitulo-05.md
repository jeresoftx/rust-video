# Ejercicio: hacer explícito el umbral

Una detección sintética tiene confianza `0.65`. Crea umbrales de `0.60` y
`0.70`, e indica cuál la acepta. Después explica qué información faltaría para
decidir si alguno es apropiado para un producto real.

La [solución](../../examples/soluciones/capitulo-05.rs) solo demuestra la
regla mecánica; no evalúa un modelo ni afirma precisión.
