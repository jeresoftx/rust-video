# Ejemplos

Los ejemplos acompañan el draft de los nueve capítulos y progresan desde
metadatos de frame hasta una salida anotada determinista.

Ejecuta uno con Cargo, por ejemplo:

```bash
cargo run --example ch09_deterministic_pipeline
```

Las soluciones de ejercicios están en [soluciones/](soluciones/). Ningún
ejemplo usa una cámara, FFmpeg, datos privados ni un modelo de IA real.
